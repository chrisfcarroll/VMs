The first thing you will need to do on a brand new machine is

1. Open an Admin Powershell and run this command

   Set-ExecutionPolicy RemoteSigned

See https:/go.microsoft.com/fwlink/?LinkID=107116 for details.

2. After that, look at 

  install-ahk-macos-typography-pwsh-profile-for-netdev.ps1

  To see if it might suit your tastes. Or otherwise, just run it.
